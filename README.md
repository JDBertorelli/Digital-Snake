# 🐍 Classic Snake Game

Una recreación del clásico juego de la serpiente (*Snake*) desarrollada en HTML5 Canvas, CSS3 y JavaScript (Vanilla). El objetivo es comer la mayor cantidad de alimento posible para aumentar tu puntuación y hacer crecer la serpiente, evitando chocar contra las paredes o contra tu propio cuerpo.

---

## 🎮 Características

* **Controles fluidos:** Respuesta inmediata con las teclas de dirección o WASD.
* **Sistema de puntuación:** Marcador en tiempo real de la puntuación actual y récord alcanzado (*High Score*).
* **Físicas y colisiones:** Detección precisa de colisiones con los bordes del tablero y la cola.
* **Diseño retro y responsive:** Estilo limpio adaptado para jugar en el navegador.

---

## 🕹️ Controles

| Acción | Teclas (Teclado) |
| :--- | :--- |
| **Mover Arriba** | Flecha Arriba (↑) / Tecla W |
| **Mover Abajo** | Flecha Abajo (↓) / Tecla S |
| **Mover Izquierda** | Flecha Izquierda (←) / Tecla A |
| **Mover Derecha** | Flecha Derecha (→) / Tecla D |
| **Reiniciar Juego** | Tecla R / Clic tras perder |

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura de la página y elemento `<canvas>`.
* **CSS3:** Estilos visuales, centrado e interfaz retro.
* **JavaScript (Vanilla):** Lógica del bucle principal (*Game Loop*), renderizado gráfico y detección de eventos de teclado.
